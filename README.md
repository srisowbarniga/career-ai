# CareerAI

Full-stack AI-powered career guidance platform built to help students and job seekers get personalized career direction.

## 🚀 Live Demo
- Frontend: [career-ai-frontend](your-frontend-vercel-link)
- Backend: [career-ai-backend-pied.vercel.app](https://career-ai-backend-pied.vercel.app)
- Full project link :[https://career-ai-frontend-wheat.vercel.app]

## 🛠️ Tech Stack
- Frontend: React.js
- Backend: Node.js, Express
- Database: MongoDB
- AI: Groq API (LLaMA 3.3-70B)

## ✨ Features
- AI-powered career recommendations & roadmap
- AI chatbot for career guidance
- Resume generator with 3 templates
- College finder
- Skill gap analysis
- Exam tracker
